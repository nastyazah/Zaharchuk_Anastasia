# Менеджер нотаток (Варіант 4)

React-застосунок для роботи з нотатками: створення, видалення, пошук за заголовком.

## Запуск

```bash
npm install
npm run dev
```

Відкрити http://localhost:5173

## Структура

```
src
├── components
│   ├── Header.jsx
│   ├── NoteForm.jsx
│   ├── NoteSearch.jsx
│   ├── NoteList.jsx
│   ├── NoteItem.jsx
│   └── Footer.jsx
├── context
│   └── NoteContext.jsx
├── App.jsx
├── index.jsx
└── index.css
```

Детальне пояснення коду і теорії — у файлі `ПОЯСНЕННЯ.md`.
